# dev-sop

dev-sop 是一个 ZCode 插件：规格驱动开发 SOP 门禁，在任何代码编辑前强制执行需求澄清访谈、Web 调研、规格与线框审批、任务书与测试计划、TDD、UI 量化验收与测试预算纪律，并内置 code-worker 执行代理。

## 安装

三种方式任选其一：

1. **GitHub 安装**：ZCode 插件市场 → 添加 → `https://github.com/FM1503/dev-sop`
2. **Gitee 安装（国内推荐）**：`https://gitee.com/fm1503/dev-sop.git` —— **注意必须带 `.git` 后缀**（ZCode 只把 .git 结尾或 github.com 域名的 URL 识别为 Git 市场，Gitee 裸地址会被当作直链 JSON 解析而报错）
3. **本地安装**：clone 或下载仓库后，把仓库根目录拖入添加框
