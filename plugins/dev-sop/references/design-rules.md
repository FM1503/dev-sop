# 设计规范（dev-sop 内置）

> 硬校验规则由插件内置的 `hooks/ui-analyzer.mjs`（Web）与 `hooks/lvgl-check.mjs`（LVGL）自动校验，
> 位于插件安装目录下；软指导不强制，用于线框设计阶段自查。

## 一、硬校验规则（量化，校验器自动执行）

| 规则 | 量化标准 | 级别 | 适用 |
| --- | --- | --- | --- |
| 4px 对齐网格 | 元素 x/y/w/h 均为 4 的倍数 | warning | Web / LVGL |
| 触控目标 | 可交互元素 w、h ≥ 44px | error | Web / LVGL |
| 最小字号 | 含文本元素 fontSize ≥ 12px | error | Web |
| 最大字号 | fontSize ≤ 48px | warning | Web |
| 对比度（WCAG AA） | 文本前景/背景对比度 ≥ 4.5:1 | error | Web |
| 越界 | 元素矩形不得超出屏幕/视口（容差 1px） | error | Web / LVGL |
| 重叠 | 互不包含的两元素矩形不得重叠（交叠面积 > 4px²，同层级/同 zIndex） | error | Web / LVGL |
| 布局混用 | 同一 LVGL 容器启用 flex 后子对象不得再用 `lv_obj_set_pos` | warning | LVGL |
| 尺寸适配 | 硬编码 px 尺寸占 `set_size` 类调用比例 ≤ 70%（其余用 `lv_pct()`） | warning | LVGL |
| 偶数像素 | `lv_obj_set_pos` 坐标使用偶数 | warning | LVGL |

说明：

- **对比度亮度公式**（WCAG 相对亮度）：
  `L = 0.2126·R + 0.7152·G + 0.0722·B`，其中每通道 `c/255` 后做伽马校正：
  `c ≤ 0.03928 ? c/12.92 : ((c+0.055)/1.055)^2.4`；
  对比度 `C = (L亮 + 0.05) / (L暗 + 0.05)`。含 alpha 通道或不可解析的颜色跳过该项（计入 skipped）。
- **越界/重叠定义**：矩形相交面积大于 4px² 且互不包含、且无法区分层级（Web 同 zIndex / LVGL 同级绝对定位）时报告；
  无法确定父子关系时按"同层级同框即报告"的简化规则处理。
- **LVGL 单容器单布局**：一个容器要么用 flex（`lv_obj_set_flex_*`）统一排布子对象，要么全部绝对定位；
  越界与重叠校验基于 `#define` 中含 HOR/WIDTH、VER/HEIGHT 的屏幕尺寸声明，未声明时跳过越界校验并给出 warning。

## 二、软指导（线框设计阶段自查，不强制）

- **间距节奏**：以 8px 为基本间距单位（8/16/24/32），留白分三级——页面级（区块之间）、组件级（组件内部）、
  元素级（图标与文字之间）；宁可多留白，不要拥挤。
- **字号阶梯**：正文 12–16，次级标题 20–24，主标题 32；优先从这个固定阶梯取值，不造中间值。
- **色彩克制**：一主色 + 一辅色 + 中性色阶（灰阶）；语义色仅用于成功/警告/错误等语义场景，
  不做装饰用；大面积区域用中性色，彩色留给关键动作。
- **层级表达**：用阴影、尺寸、明度对比表达层级，而非到处加边框线框；同层元素保持一致的内边距与圆角。
- **LVGL Flex 优先**：列表、设置项、表单、工具栏等常规排布优先 flex（`lv_obj_set_flex_flow`）；
  绝对定位适用于弹窗、悬浮层、指示器等确需自由摆放的场景，并需在 spec 中说明理由。
- **密度原则**：信息密度服从使用场景——嵌入式小屏宁可分页/滚动，不要把元素压到低于触控目标与最小字号。
